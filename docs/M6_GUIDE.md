# Самостійна програма з Proto Engine

## Експорт із редактора

1. Відкрийте проєкт або приклад `examples/ProtoStandalone/Launch-Standalone.cmd`.
2. Збережіть сцену та код C++. Експорт використовує стартову сцену з `project.proto.json`.
3. Натисніть **Експорт .exe**. Журнал показує компіляцію, підготовку ресурсів і результат.
4. Кнопка **Папка останньої збірки** відкриє `Build/<build.name>` у папці проєкту.
5. Запустіть `.exe` всередині цієї папки. Для перенесення скопіюйте всю папку збірки.

Під час експорту інтерфейс редактора залишається доступним, а обчислення 3D-сцени
призупиняються. **Stop** скасовує підготовку. Помилка або скасування залишає
попередню успішну збірку; при успішному оновленні вона зберігається поруч у
папці з суфіксом `.previous-<UUID>`.
Перед повторним експортом закрийте Player, запущений із попередньої папки збірки.

Для запуску потрібні Windows x64 та сумісний драйвер Vulkan 1.3. Компілятор,
редактор, Python і авторські `.gltf/.glb` файли для готової збірки не потрібні.
`.exe` знаходить дані біля себе незалежно від робочої папки процесу.

## Графіка у Player

**F1** відкриває налаштування. Вибір профілю заповнює параметри; **Застосувати**
передає їх рендереру, **Скасувати** відкидає незастосовані зміни.

| Параметр | Дія |
| --- | --- |
| Low / Balanced / High / Custom | Готові значення або власна комбінація |
| Масштаб рендерингу | 25–100% від розміру вікна; інтерфейс залишається чітким |
| VSync | Синхронізація показу кадрів; доступний режим залежить від драйвера |
| Дальність | Обмеження дальньої площини камери |
| Сонце | Увімкнення тіней, каскади, роздільність, дальність і фільтр |
| Точкові лампи | Увімкнення тіней, роздільність куба, фільтр і бюджет пам'яті |
| Пропуск верхніх mip-рівнів | Менші текстури на GPU за рахунок деталізації |

Усі три готові профілі залишають динамічні тіні сонця й точкових ламп увімкненими.
Якщо всі тіні ламп не вміщаються в пул пам'яті, освітлення обчислюється додатковими
проходами. Більший бюджет зменшує потребу в цих проходах, але використовує більше пам'яті.

Власні налаштування зберігаються в `Config/graphics.user.json`; початкові — у
`Config/graphics.json`. Щоб повернути початкові значення, закрийте Player та
видаліть лише `graphics.user.json`. Пошкоджені користувацькі налаштування
ігноруються із записом у журнал. Журнал звичайного запуску — `Player.log`.

## Додаткові дані для C++

Ресурси сцени потрапляють до збірки через свої залежності. Файли, потрібні лише
коду, оголосіть у `build.additionalAssets` проєкту як UUID або відносний шлях
усередині `Assets`. Під час відкриття/оновлення проєкту файл отримує `.meta`, а
посилання в маніфесті стає сталим UUID. Переносіть та перейменовуйте ресурс разом
із його `.meta` через файловий браузер редактора.

```cpp
void OnStart(proto::sdk::BehaviorContext& context) override {
    const auto bytes = context.GetAssetBytes(
        proto::AssetId::parse("76000000-0000-4000-8000-000000000001"));
    // bytes — незмінний span, дійсний протягом цієї сесії Player.
}
```

UUID у прикладі замініть на UUID власного ресурсу. `GetAssetBytes` повертає вже
завантажені байти, без читання диска в кадрі. Для цього способу доступу один
додатковий файл обмежено 64 MiB. Моделі пакуються окремим двійковим форматом.

## Командний рядок

```powershell
build/m6-release/bin/ProtoPackage.exe --project examples/ProtoStandalone
# Власна папка результату:
build/m6-release/bin/ProtoPackage.exe --project examples/ProtoStandalone --output Build/MyDemo
# Перевірка готової папки без вікна, GPU й запуску поведінок:
& 'examples/ProtoStandalone/Build/Proto Standalone/Proto Standalone.exe' --validate-package
```

Компіляція використовує SDK тієї ж конфігурації, що й інструмент експорту.
Готова папка містить маніфест із SHA-256 для незмінних файлів: редагуйте авторські
ресурси в проєкті й повторюйте експорт. Перевірка цілісності виявляє відсутні,
пошкоджені та зайві незаявлені файли; це не цифровий підпис видавця.
Власні повідомлення про ліцензії можна покласти в `Notices` проєкту — експорт
додає їх до `Licenses/project/notices`.

Результати перевірок та фактичні обмеження наведено у [звіті M6](M6_REPORT.md).

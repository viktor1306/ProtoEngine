# Proto Engine v0.1 — початок роботи

Готовий комплект знаходиться в `dist/ProtoEngine-v0.1`. Його можна переносити
цілою папкою в місце, доступне для запису: редактор зберігає свої налаштування
та журнали поруч із програмою.

## Запуск

- `Launch-Editor.cmd` відкриває редактор.
- `Launch-Demo.cmd` відкриває демонстраційний проєкт у редакторі.
- `Launch-Player.cmd` запускає готову демонстрацію. Для передавання іншому
  користувачу достатньо всієї папки `Player`, включно з `Data`, `Config`, shaders і ліцензіями.

Потрібні Windows x64 та драйвер Vulkan 1.3. Для готової програми GCC, редактор,
SDK і Python не потрібні. Сумісність перевірена на цьому ПК; мінімальний FPS
і робота на іншому обладнанні не сертифіковані.

## Свій проєкт

У редакторі виберіть **Файл → Новий проєкт…**, батьківську папку та назву.
Або використайте `Templates/ProtoCppEmpty/Create-Project.ps1` у комплекті:

```powershell
./Templates/ProtoCppEmpty/Create-Project.ps1 -Destination 'C:\Projects\MyProtoGame' -Name 'My Proto Game'
```

Батьківська папка повинна існувати, кінцева папка — бути новою. Створюються
сцена з кубом, площиною, камерою й сонцем, порожня реєстрація C++-поведінок
та налаштування графіки. Кожний проєкт отримує нові UUID.

Для v0.1 обирайте короткий шлях, наприклад `C:\Projects\MyProtoGame`.
Дуже глибокі authored-папки можуть перевищити ліміт Windows під час створення
тимчасової папки проєкту. Підтримка довільних шляхів понад MAX_PATH не завершена.

1. Імпортуйте glTF/GLB кнопкою в нижній файловій панелі. Текстури та залежності
   копіюються в проєкт. glTF може складатися з кількох файлів.
2. Розмістіть модель, створіть світло через **Додати**, змініть параметри в інспекторі.
   Після переміщення моделі чи лампи їхні тіні оновлюються.
3. Для роботи з файлами використовуйте нижню панель: Ctrl+C/X/V, F2,
   перетягування, Ctrl+Z/Y. Переносьте проєкт разом із `.meta`.
4. Збережіть сцену Ctrl+S. Файл `Code/Behaviors.cpp` відкривається подвійним кліком.
   Приклади Spin, MoveLight і KeyboardMove є у `Examples/ProtoM8Demo/Code`.
5. Натисніть **Зібрати C++**, додайте поведінку об'єкту в інспекторі й натисніть
   **Play**. **Stop** повертає редагування зі збереженням змін, які були до Play.
6. Збережіть сцену й натисніть **Експорт .exe**. Результат:
   `Build/<назва проєкту>`. Передавайте всю цю папку.

Код у `Code` компілюється наявним GCC 16.2.0 із CMake/Ninja. SDK у цьому
комплекті налаштований на інструменти цього ПК через `sdk/sdk.json`.
На іншому ПК для розробки потрібна відповідна збірка SDK з сумісним toolchain.
Другий Python не встановлюється й не використовується.

## Керування

| Дія | Клавіші |
| --- | --- |
| Огляд у редакторі | ПКМ + миша; ПКМ + WASD/Q/E; Shift прискорює |
| Фокус на об'єкті | F |
| Маніпулятори | W / E / R — позиція / обертання / масштаб |
| Вільна камера демонстрації | WASD/Q/E — рух; стрілки — огляд; Shift прискорює |
| Рух об'єкта з KeyboardMove в демонстрації | Space підіймає об'єкт |
| Зупинити Player | Escape |
| Графіка готової програми | F1 |

У F1 доступні Low/Balanced/High/Custom, VSync, масштаб рендера, дальність,
розмір і фільтр тіней сонця/ламп, бюджет карт тіней та рівень текстур.
Пресети зберігають динамічні тіні; зменшення якості виконує користувач.
Деталі експорту та відновлення графіки: [M6_GUIDE.md](M6_GUIDE.md).

## Межі v0.1

Є PBR, OPAQUE/MASK, glTF/GLB, сонце й точкові лампи з динамічними shadow maps,
проєкти, історія редагування, C++ та самостійне пакування. Фізика, зіткнення,
BLEND/скло, імпортована/скелетна анімація й ray tracing відкладені.

Перевірки описані у [M8_REPORT.md](M8_REPORT.md), продуктивність — у
[M7_REPORT.md](M7_REPORT.md). Вартість кадру залежить від сцени та налаштувань;
загальне прискорення GPU/FPS і фіксований FPS для довільної сцени не встановлені.

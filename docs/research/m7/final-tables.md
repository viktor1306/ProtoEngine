## Editor supplement

Валідними є `editor-reference` і `editor-final`; старий `editor-baseline` виключений через stale objects. Reference зібрано зі свіжого `.cache/m7-editor-reference-source` у `build/m7-editor-reference`; build log фіксує компіляцію Math 15/129, View 52/129 і Renderer 56/129. Для всіх чотирьох груп фактичний viewport — **989×738**, розміри стабільні, GPU-діапазон повний. `CPU16` — process CPU, нормалізований на 16 логічних процесорів; `sceneFrames` подано як session/timed. У всіх сирих звітах timedSceneFrames дорівнює timedRenderedFrames.

## Asset lifecycle

У кожній серії було 3 asset-запуски по 12 циклів. Перевірки weak owners, hash/ID restoration і cleanup пройшли для кожного циклу; candidate і reference використовують той самий `ProtoAssetBenchmark.exe`, SHA-256 `7284cc2b0c7f3d5f50ea324670222058c7de040a2f05d7d41a1076851894cff9`.

| Серія | Initial import | Cooked cold | Warm load | Material/document load-unload | private / working peak, B |
|---|---:|---:|---:|---:|---:|
| reference | 95.134 | 83.558 | 28.980 | 259.197 | 20750336 / 26726400 |
| final | 105.907 | 86.719 | 27.183 | 251.527 | 21610496 / 26894336 |

Медіани послідовності move (redo/undo/redo-again/final-undo): `93.056/89.867/90.153/90.799 → 109.649/115.320/114.229/116.241` мс; copy: `68.531/62.819/67.593/59.552 → 88.439/79.163/85.222/75.233` мс. GPU-тест пройшов 12/12 циклів із 0 помилок validation: VMA після unload залишалася **50,461,696 B**, а максимум після load — **50,505,728 B**.

Ці результати є описом конкретних запусків, а не універсальним FPS чи висновком про відсутність регресії. p99 для запусків із <1000 кадрів має мало спостережень; ліміт спільних ресурсів інтегрованої GPU не є фізичною VRAM.

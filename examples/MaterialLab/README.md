# Material Lab

Запуск: `Launch-MaterialLab.cmd`.

Чотири сфери, одна спільна геометрія: синя кераміка з normal map, золото,
шорстка мідь і дзеркальна кераміка. Оберіть сферу в ієрархії або 3D-вікні й
прокрутіть інспектор до розділу «Матеріал». Зміни матеріалу впливають на всі
об'єкти, що його використовують. ПКМ — огляд, колесо — масштаб, F — фокус.

Фіксоване освітлення призначене для перегляду PBR. Динамічні сценові лампи
й тіні буде додано в M3. Площина в цьому прикладі є Unlit-примітивом.

Для перенесення копіюйте всю папку з `Assets/` та `.meta`. `.proto/` —
відновлюваний кеш; він не потрібний для перенесення.

# Proto Playground

Запустіть Launch-Playground.cmd, потім натисніть **Play**. В окремому вікні Player:

- Куб обертається завдяки Spin.
- Тепла точкова лампа рухається завдяки MoveLight; тіні перераховуються з поточної геометрії.
- **WASD / стрілки** рухають куб, **Space** піднімає його на 0,5 м.
- **Escape** закриває Player; **Stop** у редакторі також завершує запуск.

Код лежить у Code/Behaviors.cpp. Подвійний клік на файлі відкриває панель C++;
збережіть зміни та натисніть **Зібрати C++**. Виберіть куб або лампу й прокрутіть
інспектор до розділу **Поведінки**, щоб змінити параметри або прикріпити клас.
Play використовує поточні незбережені параметри сцени. Після завершення запуску
редактор зберігає початковий стан і Undo/Redo.

Новий проєкт можна створити через меню **Файл**. У старому проєкті M4 файл
Code/Behaviors.cpp міг містити лише коментар: замініть його власною явною
функцією реєстрації за [посібником SDK](../../docs/M5_SDK_GUIDE.md).

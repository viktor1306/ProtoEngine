# Лабораторія світла

Відкрийте `Launch-LightingLab.cmd`. На сцені є сонце, тепла й блакитна
точкові лампи, чотири сфери зі спільною геометрією та стійки.

Оберіть «Тепла лампа · рухайте XYZ» в ієрархії або її позначку у вікні.
Перетягуйте поле позиції X/Y/Z: світло й тіні змінюються одразу.
Зміна кольору або інтенсивності використовує вже готову карту тіней.
Для сонця змінюйте обертання. Ctrl+Z скасовує одну завершену зміну.

У меню «Вигляд → Налаштування освітлення» доступні якість карт, каскади,
дальність, фільтрація й бюджет пам'яті. Значення застосовуються кнопкою
«Застосувати» та зберігаються зі сценою.

Моделі та текстури — оригінальні матеріальні сфери Proto Engine з M2.
Окрема копія джерела й `.meta` зберігається в `Assets/`; приклад MaterialLab
залишається окремим. Підготовлений кеш створюється локально при відкритті.
